## 原始需求和原生行为

用户希望在 PRD 富文本编辑器中通过界面插入表格和设置文字颜色。上游规格预览使用 `SimpleEditor` 并以 Markdown 作为编辑内容格式。当前依赖产物含 Tiptap 的表格支持和背景高亮。

## 实际实现

历史建议在工具栏和表格上下文菜单增加表格操作，并评估文字颜色扩展及其保存后在预览中的表现。当前上游依赖产物未检出 `insertTable` 和 `setColor` 命令使用，本地相关路径无有效差异。未找到本地定制的实现证据。

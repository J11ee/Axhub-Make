# CUST-013 复制原型路径时使用侧栏名称

- 模块：管理端原型侧栏
- 类型：缺陷修复
- 状态：已实现
- 首次提出、首次实施和最近更新日期：2026-11-19

## 原始需求和原生行为

DCOP 原型 `maoming-document-flow` 的侧栏标题是「茂名发展集团协同办公」，资源接口仍返回「茂名公文办理（审批流管理与通用弹窗）」。上游基线 `45b7c6e` 的侧栏菜单把资源对象交给 `useIdeActions.handleCopyItemPath`，该函数用资源的 `displayName` 生成 Markdown 链接。两个标题不一致时，侧栏渲染和剪贴板输出采用了不同名称。

## 实际实现

在 `ContentPanel.renderItemActions` 的「复制路径」入口局部使用该原型行正在显示的树节点标题（P4），继续调用原有路径解析和剪贴板处理函数（P0）。树节点没有标题时沿用资源标题。链接目标由资源的已有路径解析，原型标识、真实目录和持久化元数据均沿用原值。改动仅作用于原型侧栏复制路径。

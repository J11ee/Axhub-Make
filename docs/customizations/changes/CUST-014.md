# CUST-014 删除当前原型后回到新建引导

- 模块：管理端原型侧栏
- 类型：修改
- 状态：已实现
- 首次提出、实施和最近更新日期：2026-11-19

## 原始需求和原生行为

原有删除处理成功后会清空当前预览，再刷新原型列表。用户明确要求仅当被删除的是当前打开的原型时进入新建引导，删除其他原型时应保留当前预览。

## 实际实现

局部调整现有删除后的选择处理（P4）。删除成功后，按当前项目和当前预览判断是否进入引导。删的是当前原型时清理待恢复的资源目标并复用新建引导入口。删的是其他原型时只刷新资源列表。接口、持久化数据和 AI 引用处理沿用现有行为。

## 上游升级影响

核对删除成功回调和新建引导抑制自动选择的行为。无需迁移数据。

反向应用本次前端选择与测试的改动并重新构建。删除数据沿用项目备份或版本恢复流程。

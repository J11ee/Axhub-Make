# CUST-015 折叠原型下的文件夹

- 模块：管理端原型侧栏
- 类型：新增交互
- 状态：已实现
- 首次提出、实施和最近更新日期：2026-11-19

## 原始需求和原生行为

用户要求从原型文件的右键菜单一次收起其下各级页面文件夹，并通过原型行尾箭头单独控制原型展开和收起。上游基线 `45b7c6e` 和现有页面树（CUST-002）以分组为单位切换展开，顶层页面默认跟随当前原型显示。

## 实际实现

`ContentPanel` 在现有原型菜单中加入「折叠所有文件夹」，通过 `getPrototypePageBranchKeys` 取出所有文件夹的键并清除它们的展开状态。顶层条目继续显示，带子页的页面保留自己的展开状态。菜单在该原型没有已展开的文件夹时禁用。

点击原型行右侧箭头切换页面树是否可见。再次展开时沿用各级文件夹和页面的展开状态。两项操作只影响侧栏显示，当前预览页继续显示，切换原型时沿用原先的自动展开逻辑。

沿用共享菜单和页面树状态（P0），在菜单和原型行渲染处局部接入（P4）。历史原型的平面清单和分组清单沿用现有读取入口。

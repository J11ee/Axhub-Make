# CUST-016 拖动调整侧边栏宽度

- 模块：管理端桌面侧栏
- 类型：新增
- 状态：已实现
- 首次提出、首次实施和最近更新日期：2026-11-19

## 原始需求和原生行为

本次会话的截图显示深层原型目录标题被截断，用户要求拖动侧栏调整宽度。上游基线 `45b7c6e` 的桌面侧栏和折叠浮层固定为 240 像素。原组件没有宽度配置或扩展入口，因此采用 P4 局部修改侧栏壳组件及其样式。

## 实际实现

展开侧栏的右边缘提供拖动手柄，调整范围为 200～480 像素。焦点在手柄上时，左右方向键每次调整 16 像素，Home 和 End 分别到达下限和上限。组件在收起后重新展开时沿用本次调整的宽度，刷新后恢复默认 240 像素。折叠后的悬浮预览保留原始尺寸和触发逻辑。本次修改涉及桌面布局与侧栏内部状态，沿用现有目录数据、项目接口和 AI 调用链。
